# DeskBuddy.
READ ALL OF THIS BEFORE INSTALLING ANYTHING
The DeskBuddy is an accessory that can be put wherever you want,it can be powered from your standard PC as its powered by an Esp32 Dev module











To make the DeskBuddy you will need:
Any Esp32 modules that have an antenna,a normal button,a touch button,a 0'96 inch oled screen






It has 6 functions:
1) Check the weather
2) Wifi test in percentile and RSSI (dBm)
3) Timer of up 24 hours
4) Dino game
5) Heads or tails
6) Petting the DeskBuddy
